## 🔧 HOW TO UPDATE SUBSCRIBER DETAILS

### **Edit Personal Information**
1. Open Profile page
2. Click **"Edit Profile"** button
3. Update fields:
   - Name
   - Phone
   - Address
   - Preferences
4. Click **"Save Changes"**

### **Change Email**
1. Profile page → Account Settings
2. Click **"Change Email"**
3. Enter new email
4. Confirm via email link
5. Email updated ✅

### **Update Payment Method**
1. Profile → Billing section
2. Click **"Manage Payment Methods"**
3. Add new card or bank account
4. Set as default payment
5. Remove old payment method

### **Change Password**
1. Account Settings
2. Click **"Change Password"**
3. Enter current password
4. Enter new password (2x)
5. Click **"Update Password"**

## 📥 DOWNLOAD SUBSCRIBER DETAILS

### **Export as PDF**
1. Profile page
2. Click **Download** or **⬇️ Export**
3. Select format: **PDF**
4. File downloads to your device

### **Export as CSV** (For Records)
1. Billing/Usage section
2. Click **Export Data**
3. Select: **CSV Format**
4. Open in Excel/Sheets

### **Export Entire Account**
1. Settings → Data & Privacy
2. Click **"Request Data Export"**
3. Receive email with ZIP file
4. Contains all your account data

## 🆘 TROUBLESHOOTING

### **Issue: Can't Find Profile Section**
**Solution:**
- Refresh page (F5)
- Clear browser cache
- Try incognito mode
- Check if logged in

### **Issue: Information Not Loading**
**Solution:**
- Check internet connection
- Wait 30 seconds
- Refresh page
- Try different browser

### **Issue: Can't Edit Information**
**Solution:**
- Verify you're logged in
- Check account status (active)
- Try on desktop browser
- Contact support if issue persists

### **Issue: Old Information Showing**
**Solution:**
- Hard refresh: Ctrl+Shift+R
- Clear cookies for site
- Log out and log back in
- Wait for sync (up to 1 hour)
